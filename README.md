# EvoJump

EvoJump is a Python toolkit for simulating stochastic trajectories and
examining their distributions at selected times. It includes data quality
checks, trajectory models, cross-sectional statistics, and visualizations.

- [Read the package guide](docs/package-guide.md) for installation and use.
- [Browse the documentation](docs/README.md) and [Sphinx source index](docs/index.rst).
- [Build the manuscript](docs/manuscript/README.md) from local numerical fixtures.
- [Consult the released edition](https://doi.org/10.5281/zenodo.22664675).

Requires Python 3.11 through 3.14. [Release history](docs/releases/CHANGELOG.md) · [Apache License](LICENSE)
